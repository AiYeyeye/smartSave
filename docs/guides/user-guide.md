# 智栏使用手册

语言默认简体中文。完整设置的每个页面顶部、侧栏快速设置的首项都可以选择 English，界面、右键收藏菜单、地址栏搜索提示和工具栏状态会立即同步切换；已有输入和进行中的任务会保留。书签名称、个人规则和模型原文保持原样。浏览器扩展管理页中的扩展名称、说明和快捷键描述由浏览器语言控制。

把智栏当作浏览器书签的一个更方便的入口：**先用本地搜索，需要时再连接 AI。** 书签仍保存在 Chrome / Edge 中，不需要注册智栏账号。


## 最近收藏与按时间查找

搜索框下的“目录 / 最近收藏 / 历史”在同一行展示。选择“最近收藏”，按新增时间倒序查看；可选今天、近 7/30/90/360 天或全部时间，再输入关键词筛选。默认范围为近 90 天；收藏时间缺失的旧书签仅在全部时间显示。时间来自浏览器的新增记录，导入或重建后的时间可能不同于最初收藏日期。

例如输入“我最近收藏了一个画流程图的网站”，点击“AI 帮我找”：先在本地按收藏时间筛出近 90 天，再按相关目录和本地命中优先分批检查。普通查询找到首批匹配后可点击“继续搜索剩余书签”；明确要求“全部”时持续检查。全部检查完仍没有确认匹配时，自动补查第 91～360 天，不重复发送已检查的书签，也不继续自动扩大到全部时间。“上周”“近一个月”等常见时间描述按指定范围查询；手动时间筛选与明确描述取交集，不自动扩大。失败或取消不会触发扩大，已确认结果和无法确定的结果保留。普通 AI 查询没有“最近收藏”条件且未选最近视图时，仍搜索全部允许范围。


## 1. 安装与打开

目前提供源码安装。按 [安装说明](install.md) 构建并加载 `extension/dist`，然后把智栏固定到工具栏。

点击智栏图标打开侧栏。默认从网页左侧浮出，按 Esc 或点空白处收起；在“外观”里可改为浏览器侧边栏。浏览器内部页面会使用浏览器侧边栏。点“设置”进入完整工作台。

目录会记住展开状态和最后浏览位置。点开书签、关闭侧栏后再次打开，或切到设置、搜索后返回目录，会回到原来附近；浏览器重启后也保留。若原书签已被删除，会回退到仍存在的目录或附近位置。位置记录只在本机保存，不会自动打开网页。

![书签目录，全部为演示书签](../media/screenshots/01-bookmarks.png)

## 2. 查找与管理书签

- 在搜索框输入标题、网址或目录名，也支持中文拼音和首字母；普通搜索在本机完成。
- 点击结果打开书签；右键或点击书签操作按钮，可编辑、移动、复制链接或删除。删除时确认框只询问“是否确认删除？”。操作成功后直接更新列表，不在顶部保留完成提示；操作失败或结果未知时仍会显示提示。
- 快捷键：`Alt+Shift+K` 打开搜索；智栏界面内 `Ctrl+K`（Mac 为 `⌘K`）聚焦搜索。冲突时到扩展快捷键设置修改。
- 地址栏输入 `zl`，按 Tab 或空格，再输入关键词。选择候选打开书签，直接回车进入完整搜索页。

![本地搜索演示](../media/screenshots/02-search.png)

## 3. 连接 AI（可选）

1. 打开 **设置 → AI 服务 → 添加连接**，选择已有的服务，填写地址和 API Key。
2. 获取模型列表，明确选择一个模型并保存；列表不支持时可手动填写模型 ID。
3. 为智能收藏、导入、搜索和整理分别指定模型，检查 **隐私与规则** 中的发送范围。
4. 保存后即可开始使用；如需检查连接，可使用服务设置中的合成连接测试。

首次安装后，侧栏会显示配置 AI、收藏、搜索和整理的操作步骤。关闭后不再自动显示，可从侧栏设置中的“新手操作步骤”重新打开。

AI 费用由你的服务商收取。记住密钥会把密钥明文保存在浏览器扩展本地存储；添加连接当前默认勾选记住，请按需取消。临时密钥在原页面关闭或刷新后会丢失，原生收藏后台自动归类通常需要已保存的凭据。详细步骤见 [模型设置](model-setup.md)。

## 4. 收藏、AI 搜索与整理

**找回浏览过的网页：** 搜索框下选择“历史”，第一次点击“启用历史查询”并授予权限。通过同一行的“目录”“最近收藏”和“历史”切换浏览内容。可以查看最近访问，或按标题、网址、域名、拼音查找，选择近 7 天、近 30 天、自定义日期或全部可用历史。读取达到单批上限时会提示“继续读取历史”；“全部可用历史”表示时间范围，并不承诺一次读完全部记录。

输入“上周看的那个画流程图的网站”等描述，点击“AI 查历史”。沿用“智能搜索”分配的模型，先理解时间与关键词，再比较最多 80 条候选；日期不会超出你选定的范围。结果来自真实访问记录，不包含网页正文，可能遗漏语义相关但未召回的网页。每行只显示网站图标和网页名称；点击打开，右键或点击行内菜单可在其他窗口打开、复制或收藏。访问时间和已收藏状态放在悬停提示及菜单中。收藏卡保留目录选择、可选 AI 分类和最终确认，不会自动保存。

普通历史查询在本机进行，不建立持久历史数据库。浏览器删除历史或撤销权限后，搜索缓存及待返回的 AI 结果会失效；在日期范围旁的菜单中选择“关闭历史访问”可以撤销权限，不会删除浏览器历史。已经主动打开的收藏草稿作为待保存书签保留，可取消。浏览器地址栏的 `zl` 仍只搜索书签。

**收藏：** 配置好智能收藏后，像平常一样点浏览器星标或按 `Ctrl+D`。智栏先尝试本地规则，再按配置调用 AI 归类新书签。未配置或失败时书签留在浏览器中，可在“收藏记录与调试”查看处理结果、纠正目录或撤销。网站规则需要另行确认保存。

**搜索范围：** “搜索文件夹”默认是“全部文件夹”。选择一个文件夹后，本地搜索、最近收藏和 AI 搜索都只查找该文件夹及其子文件夹，并同时应用“收藏时间”筛选。继续搜索和自动补查较早收藏也保留这个文件夹范围。更换文件夹会结束当前 AI 搜索并清除继续状态，之后可重新点击“AI 帮我找”。选择仅保留在当前页面中；所选文件夹被删除后，需要重新选择。历史搜索不受此设置影响。

**AI 搜索：** 不记得名字时，输入“之前收藏的那个画流程图的网站”，点击“AI 帮我找”。范围内超过 100 条且分布在多个目录时，先让 AI 根据目录路径、数量和少量标题样本排列优先级，再结合跨目录的本地命中分批检查，每批最多 100 条。普通查询找到首批匹配后先展示结果，可点击“继续搜索剩余书签”；要求“所有/全部”时持续查完。目录排序失败时按本地顺序继续。没有确认匹配则继续查找，所有候选都保留在待查范围中，不把未检查条目当成不相关。界面仅保留操作按钮、覆盖进度、结果与必要的异常提示，不再显示辅助说明或重复的完成提示；无法确定的项目仍可展开，取消或失败保留已完成结果。模型只看到书签元信息，不读取网页正文，也不保证判断完全准确。

明确的网站查询（如“我想要所有的知乎文章”或 `site:zhihu.com`）可直接在本地找全，包括问答、专栏等页面；`folder:"学习资料"` 可搜索唯一同名文件夹及子文件夹。含额外主题、否定或目录重名等情况会进入上述 AI 查找流程。隐私排除的书签仍可本地搜索，不会发送 AI；需要语义判断时，本地命中会单独列出。搜索期间书签变化会提示重新搜索，不能把旧结果当作最新全量结果。

**整理：** 进入“AI 整理”，选择目录并检查规则与模型。系统先分批分析范围内全部允许发送的书签标题、网址和原目录，再汇总主题生成分类草案；即使没有子文件夹，也能从书签内容建立分类。逐条分配时若发现缺少类别且尚未开始人工审核，会自动修订一次分类，并按新版分类重新核对全部书签。每批完成即可查看并审核分类；最后统一查看完整分类树、移动建议、明确保留和待确认的书签；漏答不会当成“保持原位”。待确认书签没有单独移动建议，但所选文件夹变更仍可能影响路径。

“只整理未分类的书签”指所选目录下直接收藏的书签，可为它们新建分类，但不搬动、重命名或清理已有子目录。分类草案可以调整，整理范围、分类方式、层级和保护规则仍是约束。分析和分类核对都可能调用模型，修订会增加请求和 Token 用量。关闭工作台后可重新打开查看后台进度；中断后手动继续，已完成的分析会保留。旧版本保存的任务仍沿用原来的文件夹确认流程。**最后点击确认执行前，生成方案不会修改书签。**

![AI 整理的范围选择](../media/screenshots/03-organize.png)

**重复清理：** 在整理页进入重复检查，区分精确重复和疑似链接变体，检查原始链接，选择保留项后确认删除。疑似重复不代表内容一定相同。

点击浏览器星标或使用 `Ctrl+D` 收藏后，智栏在后台完成归类和名称建议，再在浏览器右上角的扩展图标处自动弹出确认浮层（扩展弹出面板，需 Chrome / Edge 127+），不新建窗口、标签页或任务栏项。浮层直接填入 AI 建议的名称和目录；目录用可展开、收起的文件夹树选择，打开时展开到当前目录，名称与目录一起确认，详情默认折叠；收起详情或目录树后，浮层随内容缩回。闲置后仍可直接确认，已填写的内容会保留；若书签或目录已在别处改变，会提示重新核对。连续收藏只显示一个浮层并排队（显示 1/N），后到的结果不会覆盖正在编辑的内容；浮层因点击网页而关闭后，再点扩展图标或侧栏“待确认 N 项”可恢复原来的草稿。没有修改时确认只结束复核；关闭或“稍后处理”保留书签和归类结果。浏览器窗口不在前台、处于全屏，或浏览器自带的“已添加书签”小面板仍开着时，浮层不抢焦点，会在窗口重新可用后出现；约一分钟仍无法显示时，在扩展图标上提示，点图标即可打开。扩展自己的收藏快捷键和右键菜单也在同一浮层中收藏当前网页。命中本地规则时也会等待名称建议结束。导入期间，以及一秒内出现大量新增（如同步）时不自动弹出；浏览器事件不区分用户新增和同步新增，单条同步新增仍可能弹出。撤销归类可在浮层“详情”或收藏记录中操作，网站规则仍须单独明确确认。

## 5. 导入、导出与恢复

**导入：** 支持 HTML、JSON、CSV、TXT、Markdown。选择文件和目标目录，检查解析与分类结果，再确认导入。浏览器导出的书签 HTML 通常最方便。

**导出：** 在“导出与备份”选择范围，再选 HTML（迁移到浏览器）、JSON（程序使用）或 Markdown（阅读）。导出保留原始网址，**不含 API Key、模型配置、网站规则和恢复日志，也不是完整恢复备份**。

![导出与备份](../media/screenshots/04-export.png)

**恢复：** 展开“备份与恢复记录”，先预览撤销，再确认应用。若显示“结果未知”，先“核对当前状态（不重放）”，不要重复整理、清空存储或卸载。详见 [恢复说明](recovery.md)。

自动更新本地 JSON 文件是可选高级功能，只授权专用文件；后续更新会覆盖它，浏览器关闭期间不会更新。

## 6. 隐私与常见问题

在“隐私与规则”排除不想发给 AI 的目录，按需关闭“发送完整网址”和正文辅助；排除 AI 不等于排除手动导出。网址查询参数可能包含私人信息。正文辅助默认关闭。完整说明见 [隐私政策](../privacy.md)。

![隐私与规则](../media/screenshots/05-privacy.png)

| 遇到的情况 | 怎么处理 |
| --- | --- |
| 不想用 AI | 直接使用目录、本地搜索、手动管理和导出 |
| AI 提示未配置或无模型 | 在 AI 服务里检查连接和该功能的模型分配 |
| 401 / 403 | 检查 Key、服务地址及授权；不要把 Key 发给他人 |
| 超时或中断 | 保留已完成结果，检查服务，再使用界面提供的重试/继续 |
| 快捷键无效 | 在 `chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts` 检查冲突 |
| 操作结果未知 | 先核对恢复记录，不重复执行 |

## 个性化偏好与逐批审核

整理页会逐批显示已生成的分类，并把“待确认书签”单独列出。可以勾选一条或一组（每次最多 100 条），选择目标目录后确认归类，也可以写出不合理之处，点击“提交反馈并重新分类”。当前批次结束后优先重新判断所选书签；新的手动确认优先于尚未返回的 AI 建议。未生成的书签继续整理，暂停或中断后保留已保存的审核和反馈。

“内容分析”从标题、网址和原目录提取主题，不读取网页正文；“分类核对”逐条决定移动、保留或待确认。若还没有人工审核，缺少类别可以触发一次目录修订；界面明确标记第二轮，内容分析不会重做，也不会自动进入第三轮。开始人工确认或反馈后固定当前目录草案，避免重建覆盖人工决定。全部处理完后仍需查看完整方案并统一确认，才会修改原生书签。

设置中独立的 **个性化偏好** 菜单展示已记住的内容；没有记录时显示“暂无”。在智栏中手动改目录、修改 AI 建议的书签名，以及在整理页选择目录、确认归类或提交重分类反馈，都会记录。Chrome/Edge 原生书签管理器中的改目录和改名也会记录；浏览器事件不提供来源标识，其他扩展或同步造成的同类变化也可能进入记录。智栏自身的自动分类、整理、恢复写入和同目录内调序不会重复学习。直接采用 AI 名称不算人工改名；整理页明确确认归类则会记住。

偏好正文总计最多 **3000 字、10 条**（含条目间换行，按 Unicode 字符计数）。原始操作先留在本地学习队列，后台使用整理模型总结分类依据或命名习惯，成功后才保存为偏好，并与现有有效偏好合并、去重，保留最新要求。例如，明确反馈“API 教程放学习资料，不放工具”应总结为“这类教程按学习参考用途归类”，而不是重复移动记录。单次选择只支持较窄的判断；原因不明确时不编造用途或用户动机。设置中可以修改、停用、删除和添加内容，手动添加或编辑超限时也会整体压缩。失败保留原有偏好且不回滚书签，失败输入留在本地任务记录中，不自动重发。旧版超量记录会保留本地迁移副本，只有已启用且有效的内容参加更新。

后续书签搜索、整理、改名、收藏和导入分类按适用功能参考有效已启用的偏好，当前要求优先。整理审核记录意图，统一确认前不移动书签。已失效或隐私排除的证据、停用和待确认的规则不发送；历史查询和合成连接测试不使用偏好。关闭、修改或删除影响后续请求，无法撤回已发送的信息。
