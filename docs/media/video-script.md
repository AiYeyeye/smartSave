# 35 秒使用演示脚本

当前交付的 MP4 为无声真实操作，适合先查看界面；没有配音或真实 AI 生成效果。下面提供后续录制旁白或上传视频时可用的简短文字。

| 大约时间 | 画面 | 建议旁白 / 字幕 |
| --- | --- | --- |
| 0–4 秒 | 书签目录 | 这是智栏，让浏览器里的书签更好找。 |
| 4–9 秒 | 输入“流程图”，显示本地结果 | 输入关键词即可搜索，也支持中文拼音。普通搜索在本机完成。 |
| 9–11 秒 | 清空搜索、回到目录 | 点击结果就能打开，书签仍属于浏览器。 |
| 11–16 秒 | AI 整理入口 | 需要整理时，先选目录，再审核方案，最后由你确认执行。 |
| 16–21 秒 | 导出与备份 | 可以导出常见格式；操作记录帮助核对和恢复。 |
| 21–26 秒 | 隐私与规则 | 哪些目录可以发给 AI，由你设置。 |
| 26–31 秒 | AI 服务入口 | AI 是可选功能，连接你自己的服务即可使用。 |
| 31–35 秒 | 回到书签目录 | 先从本地搜索开始，让每一条收藏都用起来。 |

正式录制 AI 功能时，仅使用可公开的演示数据和限额测试凭据，完整展示预览与确认。不要用合成返回结果冒充真实模型表现。YouTube 简介可链接仓库、使用手册和实际部署后的隐私政策，避免使用“官方认证”或未测的准确率、速度承诺。
